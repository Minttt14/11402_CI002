## 2. 題目說明
有一片長條形的田地，由 .（代表需要保護的農作物）和 #（代表不長作物的荒地）組成。你可以在田地上的任何位置放置稻草人，一個稻草人可以保護自己所在的位置，以及左右相鄰的各一個位置（總共 3 個位置），算出最少需要幾個稻草人才能保護所有的農作物
- **輸入:** 第一行為測資數量 $T$。接下來每筆測資包含兩行：第一行為田地長度 $N$，第二行為長度為 $N$ 的田地狀態字串
- **預期輸出:** 每筆測資的最少稻草人數量，格式嚴格規定為 Case [編號]: [數量]
- **主要規則或限制**
  1. $0 < N < 100$
  2. 稻草人可以放置在荒地 (#) 甚至超出田地邊界的地方
- **核心任務:** 透過由左至右的掃描，找出不會產生多餘重疊的最優「貪心放置策略」，以最小化稻草人的總數

## 3. 思考邏輯與解題策略

### 初始想法

- 對於田地上的每一個位置，考慮「放稻草人」或「不放稻草人」，然後寫狀態轉移方程式來求最小值
- 想法過於複雜。對於這類「區間覆蓋」問題，每個點的覆蓋狀態其實是受前一個點牽制的

### 最終策略

- 當我們遇到「第一個還沒被保護的農作物 (.)」時，為了讓這個農作物被保護到，稻草人只能放在它的左邊、原位、或右邊。為了讓稻草人的效益極大化（向右覆蓋更多未知的區域），最聰明的選擇就是「把稻草人放在它的右邊一格」
- 使用一個 for 迴圈從左到右遍歷代表田地的字串。如果遇到 #，代表不需要保護，指標順其自然往下一步走；當遇到 . 時，代表此處必須被覆蓋，此時我們貪心地將稻草人放在它的右邊一格，這樣可以同時覆蓋當前位置、右邊位置以及右邊的右邊位置（共三格）。因此，我們將稻草人計數器加一，並且直接將迴圈指標 i 往前推進 2 格（配合 for 迴圈本身的遞增 ++i，相當於一次跳過這 3 個被覆蓋的格子），以此類推，直到掃描完完整片田地為止

## 4. 虛擬碼

```text
START
讀取測資總數 t
初始化測資編號 num = 1

當 t > 0 時 (執行 t 次迴圈)：
    讀取田地長度 n
    讀取田地字串 s
    初始化稻草人計數器 cnt = 0
    
    使用迴圈 i 從 0 到 n-1 掃描字串 s：
        如果 s[i] == '.' (遇到需要保護的農作物)：
            稻草人數量 cnt 增加 1
            將指標 i 往前推進 2 格 (i += 2)，代表跳過包含此格在內被覆蓋的 3 個格子
            
    按照規定格式輸出 "Case {num}: {cnt}"
    測資編號 num 增加 1
    t 遞減
END
```

### 正確程式碼

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int t;
    cin >> t;
    int num = 1;
    while(t--){
        int n;
        cin >> n;
        string s;
        cin >> s;

        int cnt = 0;
        for(int i=0; i<n; ++i){
            if(s[i] == '.'){
                cnt ++;
                i += 2;
            }
        }

        cout << "Case " << num << ": " << cnt << "\n";
        num ++;
    }
}
```

## 6. 差異與反思

### 關鍵差異

| 邊際情況 |  | 利用 for 迴圈條件 i < n 自然攔截 i += 2 造成的潛在越界 |
| 輸出處理 |  | 精準控制 cnt 的重置與 Case X: Y 的嚴格格式輸出 |

### 反思
- 這題完美證明了「局部最佳解可推導至全域最佳解」的 Greedy 核心。只要最左邊的 . 必須被覆蓋，把稻草人放在其右側必定不會比放在其左側或原位差。認清這個本質後，程式碼就能變得極度簡潔
- 這種利用 Greedy 解決的「區間覆蓋 (Interval Covering)」題型是非常常見的演算法樣板（如基地台架設、灑水器問題）。未來只要遇到「用最少資源覆蓋所有目標」的題型，第一直覺就要想到「由單一方向掃描，並在極限邊緣放置資源」的貪心策略
