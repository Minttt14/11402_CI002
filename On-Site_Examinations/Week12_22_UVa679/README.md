## 2. 題目說明
有一棵深度為 $D$ 的滿二元樹，節點編號依序從 1 到 $2^D-1$，每個非葉子節點都有一個開關，初始狀態為「關閉（FALSE）」，當有一顆球從根節點掉落時，如果遇到開關為 FALSE，球會往左子節點掉落，同時該節點開關切換為 TRUE;如果遇到開關為 TRUE，球會往右子節點掉落，同時該節點開關切換為 FALSE
- **輸入:** 第一行包含一個整數代表接下來有幾組詢問，每組詢問包含兩個整數，depth（樹的深度 $D$）與 ball（第 $I$ 顆落下的球），當讀入為 -1 時結束程式
- **預期輸出:** 每組詢問輸出第 $I$ 顆球最後落下的葉子節點編號
- **主要規則或限制**
  1. 根節點編號為 1，若目前節點為 $x$，其左子節點為 $2x$，右子節點為 $2x+1$
  2. 深度 $D$ 最大可達 20，球數 $I$ 最大可達 524,288
- **核心任務:** 尋找數學規律，推導出第 $I$ 顆球的落點

## 3. 思考邏輯與解題策略

### 初始想法

- 看第一顆球是往左還是往右，接下來的葉子節點應該會呈現某種規律的「線性偏移」
- 忽略了球在進入第二層、第三層之後，該子樹所接收到的「相對球數」奇偶性會重新洗牌，不能只用第一層的結果一條公式通吃到底

### 最終策略

- 動態更新相對球序
- 如果 $k$ 是奇數，這顆球是往左走的球之中的「第 $\frac{k+1}{2}$ 顆」。我們就可以放心地把當前位置更新為 now * 2，並把下一層要觀察的球序 $k$ 更新為 $\frac{k+1}{2}$。如果 $k$ 是偶數，這顆球是往右走的球之中的「第 $\frac{k}{2}$ 顆」。我們把位置更新為 now * 2 + 1，並把下一層要觀察的球序 $k$ 更新為 $\frac{k}{2}$

## 4. 虛擬碼

```text
START
1. 讀取測試案例數 n，若 n == -1 則結束
2. 執行 n 次迴圈處理每個詢問：
   a. 讀取 depth 與 ball
   b. 初始化 k = ball, now = 1 (從根節點 1 開始)
   c. 執行迴圈 (從第 1 層走到第 depth - 1 層)：
      - 若 k 是奇數 (k % 2 != 0)：
        - 球會往左走：now = now * 2
        - 更新此球在左子樹中的相對球序：k = (k + 1) / 2
      - 若 k 是偶數 (反之)：
        - 球會往右走：now = now * 2 + 1
        - 更新此球在右子樹中的相對球序：k = k / 2
   d. 輸出最終停下來的葉子節點編號 now
END
```

## 5. 錯誤程式碼 vs 正確程式碼


### 錯誤程式碼

```cpp
# include<bits/stdc++.h>
using namespace std;

int main(){
	int n;
	while(cin >> n && n != -1){
		
		for(int i=0; i<n; ++i){
			int depth, ball;
			cin >> depth >> ball;
			
			int left = 2;
			int right = 3;
			for(int i=1; i<depth-1; ++i){
				left *= 2;
				right *= 2;
			}
			
			int tmp;
			if(ball % 2 != 0){
				tmp = (ball / 2);
				cout << left + tmp << "\n";
			}
			else {
				tmp = (ball / 2) - 1;
				cout << right + tmp << "\n";
			}		
		}	
	}
}
```

**錯誤原因**

- 只在最開頭做了一次 if(ball % 2 != 0) 判斷，只決定了第一步是走 left 子樹還是 right 子樹，後面從第三顆球開始路徑就會出現錯誤

### 正確程式碼

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    while (cin >> n && n != -1) {

        for (int i=0; i<n; ++i) {
            int depth, ball;
            cin >> depth >> ball;
            
            int k = ball;
            int now = 1; 
            for (int j=0; j<depth - 1; ++j) {
                if (k % 2 != 0) {       
                    now = now * 2;
                    k = (k + 1) / 2;    
                }
                else {                
                    now = now * 2 + 1;
                    k = k / 2;       
                }
            }
            cout << now << "\n";
        }
    }
}
```

**可運作原因**

- 隨著深度每一層重新檢視 k（當前子樹的相對球序）的奇偶性，並同步更新 now 與 k 的數值


## 6. 差異與反思

### 關鍵差異

| Item | Fail Code | Correct Code |
|---|---|---|
| 邏輯 | 只在第一層判斷奇偶性，後續用固定的位移公式錯誤計算 | 層層動態追蹤，每一層都根據相對球序進行路徑與球數修正 |
| 邊際情況 | 深度大於 3 的情況下，因為子樹內部的開關狀態錯亂，完全算不準 | 任何深度都能透過迭代精確收斂到正確的葉子節點 |
| 輸出處理 | 輸出錯誤計算的加法結果 | 精準輸出跟隨球一條路走到底的最終 now 節點編號 |

### 反思

- 不需要管整棵樹的開關是紅是綠，我們只需要管「這顆球是第幾個進入這家店的人」。由於這是一棵完美的滿二元樹，奇數給左邊、偶數給右邊的分配非常公平，利用 $\frac{k+1}{2}$ 和 $\frac{k}{2}$ 就能將大問題直接折半
- 以後看到類似的題目，第一時間就要在紙上畫出流向圖，尋找奇偶數或餘數的週期規律，而不是急著開陣列
