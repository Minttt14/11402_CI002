## 2. 題目說明
有一個機器人位於一個 m x n 網格的左上角 (0, 0)，每次只能向右或向下移動一步，機器人試圖達到網格的右下角 (m - 1, n - 1)
- **輸入:** 兩個整數 m (列數) 與 n (行數)
- **預期輸出:** 機器人走到右下角共有多少種「不同的路徑」
- **主要規則或限制**
  1. $1 \le m, n \le 100$
  2. 最終的答案小於等於 $2 \times 10^9$ (可安全放在 32-bit int 中)
- **核心任務:** 找出有效計算路徑總數的方法，避免暴力遞迴導致的重複計算與超時

## 3. 思考邏輯與解題策略

### 初始想法

- DFS，從起點開始，每次遞迴都能選擇往下或往右，走到右下角時路徑數加 1
- 時間複雜度高，會超時

### 最終策略

- 動態規劃，機器人只能「向右」和「向下」，那麼走到任何一個格子 (i, j) 的方法數，一定等於「走到它上方格子 (i-1, j) 的方法數」加上「走到它左方格子 (i, j-1) 的方法數」
- 最上面那排 (第 0 列) 因為只能一直向右走，路徑數全為 1；最左邊那排 (第 0 行) 因為只能一直向下走，路徑數也全為 1，因此，直接把整個 $M \times N$ 矩陣預設為 1，就可以省去額外的邊界初始化步驟，直接從 (1, 1) 開始填表

## 4. 虛擬碼

```text
START
方法 uniquePaths(m, n):
    1. 建立一個 m 列 n 行的二維陣列 dp，並將所有格子的初始值設為 1
       (這巧妙地完成了第 0 列與第 0 行的邊界初始化)
       
    2. 使用雙層迴圈填表：
       - 外層迴圈 i 從 1 走到 m - 1 (列)
       - 內層迴圈 j 從 1 走到 n - 1 (行)
         - 計算當下格子的路徑數：
           dp[i][j] = 上方格子的路徑數 (dp[i-1][j]) + 左方格子的路徑數 (dp[i][j-1])
           
    3. 迴圈結束後，右下角格子 dp[m-1][n-1] 即為總路徑數，將其回傳
END
```

### 正確程式碼

```cpp
class Solution {
public:
    int uniquePaths(int m, int n){
        vector<vector<int>> dp(m, vector<int>(n, 1));

        for(int i=1; i<m; ++i){
            for(int j=1; j<n; ++j){
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};
```
